A Neural Net Approach to Predicting Integrated Information.

A system of interconnected nodes' integrated information can be computed by measuring the information flow of the entire system independent of its individual parts. 
This process becomes computationally intractable as the number of nodes in the system increases, hence comes the need for methods of prediction. My research looks
to solve this problem by using recurrent neural networks to predict integrated information using the prior and conditional probabilities stored in a transition
probability matrix.
